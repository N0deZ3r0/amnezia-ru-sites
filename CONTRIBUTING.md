# Участие в разработке

Спасибо, что хотите помочь. Проект небольшой и ведётся одним человеком, поэтому хорошо описанная задача
ценится не меньше, чем pull request.

## Сообщить об ошибке

Откройте [сообщение об ошибке](https://github.com/N0deZ3r0/amnezia-ru-sites/issues/new?template=bug_report.yml).
Форма просит версию Python, систему и шаги воспроизведения. Заполните их: из «не работает» ничего
сделать нельзя.

Нашли проблему **безопасности**? Не открывайте публичную задачу,
[напишите приватно](https://github.com/N0deZ3r0/amnezia-ru-sites/security/advisories/new).

## Запуск у себя

1. Склонируйте репозиторий.
2. Установите зависимость: `pip install dnspython`.
3. Обновите списки: `python update.py` (при выключенном VPN).

## Проверки перед отправкой

```cmd
python -m unittest discover -s tests -v
```

Тесты не ходят в сеть: DNS подменяется заглушкой, а списки диапазонов берутся из временного файла.
Они же проверяют, что готовые списки в `lists/` имеют формат Amnezia и не содержат повторяющихся IP.
Если вы меняете логику сбора или нарезки, добавьте тест.

## Pull request

- Одно изменение — один pull request.
- Если изменилось поведение, обновите README.
- Если вы пересобрали списки в `lists/`, укажите в описании дату сборки и размер файлов.
- Пишите по-русски.
